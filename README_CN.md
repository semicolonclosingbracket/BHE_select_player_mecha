# 关于Mod
此项目是游戏BALDR HEART EXE的Mod，允许玩家将自机切换为苍以外的机体。

# (1) 如何安装
下载文件BHE_select_player_mecha.pac，复制至游戏目录，重命名为Update[?].pac，[?]是2~9之间的数字，最终文件名应该类似Update3.pac或Update7.pac。

在安装之后，启动游戏，前往ACT设置，**找到“ネットワークへの接続”选项，将其关闭。**此Mod无法在联网下使用。

# (2) 切换自机机体
此Mod将替换深渊1 ~ 3关，每关的地图都是黑背景（练习模式中选择地图的列表的最后一个）。如果1 ~ 3关无变化，说明Mod安装失败。

选择“开始”时，自机总会被设置为苍。进入练习界面，将练习的敌机设置为想要自机要切换成的机体。进入深渊第1关，更换自机（Mod的深渊第1关的自机总是苍，并不是已被更换的自机）。之后返回装备界面，可以看到自机已被更改。此时练习的敌机不能再被更改，否则会立即闪退（也就是说只能使用与自机相同的敌机来练习）。

在进入装备界面后，**此时显示的配置是上一次使用的苍的那套武装，如果自机不是苍，不要直接更改那套武装配置。**如果要更改当前自机武装配置，先选中当前自机的其他一套武装配置。

# (3) 进入深渊的其他关卡
Mod的深渊第2关的功能为在内存中加载一份当前自机的资源，Mod的深渊第3关的功能为在内存中清除一份当前自机的资源。
在进入深渊的其他关卡时，关卡会加载一份苍（原版默认自机）和敌机们的资源（在切换关卡时自动将它们清除）。如果当前自机的资源不存在，游戏会闪退。**因此如果自机不属于敌机中的任何一种，就需要一份通过深渊第2关加载的资源。**
但深渊第2关的资源会将此种敌机的AI覆盖为默认AI，拥有特殊AI的关卡（例如深渊68的みさき）会受到影响。因此如果自机属于敌机中的任何一种，就需要确保内存中没有深渊第2关加载的资源，如果已经通过深渊第2关加载了一份资源，就进入深渊第3关将其清除。

注意：**如果内存中已经没有了深渊第2关加载的那份资源，进入深渊第3关会直接闪退。**

# (4) 播放Replay
由于原版中自机默认是苍，Replay不会记录当时实际使用的自机，游戏只会把Replay的自机设置为当前的自机。因此**如果以机体A为自机产出了一份Replay，想要正常播放此Replay，必须先将自机切换为机体A，并且在需要时通过第二关加载自机的机体资源。**

# (5) 重置此Mod带来的临时更改
选择返回标题会将自机重新设置为苍，并清除内存中的一切机体资源。但其他机体的武装配置和通过其他机体产出的Replay仍然会保留。
